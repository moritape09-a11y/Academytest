🔍 علت مشکل:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

مشکل در ترکیب tax_query بود:

❌ قبل:
──────────────────────────────────────
$tax_query_filters = array('relation' => 'AND');

if (!empty($subject)) {
    $tax_query_filters[] = array(...);
}

if (count($tax_query_filters) > 1) {
    // اضافه کردن
}

مشکل: زمانی که فقط 1 فیلتر است،
count = 2 می‌شود (relation + 1 query)
اما به درستی اضافه نمی‌شد!


✅ بعد:
──────────────────────────────────────
$tax_query_filters = array();  // بدون relation

if (!empty($subject)) {
    $tax_query_filters[] = array(...);
}

if (count($tax_query_filters) == 1) {
    // مستقیم اضافه کن
    $final_tax_query[] = $tax_query_filters[0];
} else if (count($tax_query_filters) > 1) {
    // با AND ترکیب کن
    $final_tax_query[] = array_merge(
        array('relation' => 'AND'),
        $tax_query_filters
    );
}

حالا درست کار می‌کند! ✅

قدم 1️⃣: فایل را آپلود کنید
─────────────────────────────────────────────────────────
• includes/shortcodes.php


قدم 2️⃣: مطمئن شوید رشته‌ها assign شده‌اند
─────────────────────────────────────────────────────────
از پنل مدیریت وردپرس:

1. روی "آموزشگاه‌ها" کلیک کنید
2. یک آموزشگاه باز کنید
3. سمت راست صفحه، جعبه "رشته" را پیدا کنید
4. یک یا چند رشته را تیک بزنید ✅
5. روی "بروزرسانی" کلیک کنید

همین کار را برای مدارس و معلمین هم انجام دهید!


قدم 3️⃣: کش را پاک کنید
─────────────────────────────────────────────────────────
Ctrl + Shift + R


قدم 4️⃣: تست کنید
─────────────────────────────────────────────────────────
صفحه جستجو را باز کنید

تست 1: فقط رشته را انتخاب کنید
  ↓
  رشته: "زبان انگلیسی"
  (بقیه فیلترها خالی)
  ↓
  کلیک "اعمال فیلترها"
  ↓
  باید همه موارد "زبان انگلیسی" را ببینید ✅

تست 2: رشته + شهر
  ↓
  رشته: "زبان انگلیسی"
  شهر: "تهران"
  ↓
  کلیک "اعمال فیلترها"
  ↓
  باید فقط موارد تهران را ببینید ✅
