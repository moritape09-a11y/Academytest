قدم 2️⃣: پاک کردن کش
─────────────────────────────────────────────────────────────────
▶ مرورگر:
  • Ctrl + Shift + R (Windows/Linux)
  • Cmd + Shift + R (Mac)
  • یا F12 → Application → Clear Storage

▶ پلاگین کش:
  • WP Rocket → Clear Cache
  • W3 Total Cache → Clear All Caches
  • یا هر پلاگین کش دیگری

▶ CDN (اگر دارید):
  • Cloudflare → Purge Cache
  • یا CDN دیگر


قدم 3️⃣: تست
─────────────────────────────────────────────────────────────────
1. صفحه جستجو را باز کنید
   (صفحه‌ای که شورت‌کد [edu_search] دارد)

2. شروع به تایپ کنید: "طراحی"
   ⏱️ بعد از 500ms نتایج باید بیایند!

3. چک کنید:
   ✓ Loading spinner نمایش داده می‌شود؟
   ✓ Skeleton cards ظاهر می‌شوند؟
   ✓ نتایج با animation نمایش داده می‌شوند؟
   ✓ URL تغییر می‌کند؟
   ✓ دکمه Back مرورگر کار می‌کند؟

4. فیلتر را تغییر دهید:
   ✓ شهر را انتخاب کنید
   ✓ نتایج باید فوری تغییر کنند!

5. موبایل تست کنید:
   ✓ صفحه را در موبایل باز کنید
   ✓ همه چیز باید responsive باشد


قدم 4️⃣: Debugging (در صورت مشکل)
─────────────────────────────────────────────────────────────────
اگر کار نکرد:

1. Console را باز کنید (F12)
   • خطا پیدا کنید
   • JS errors?
   • AJAX errors?

2. Network Tab را چک کنید
   • Request ارسال می‌شود؟
   • Response چیست?
   • Status code: 200 یا 404 یا 500?

3. REST API را تست کنید
   • بروید: yourdomain.com/wp-json/edu/v1/search
   • باید JSON ببینید

4. مطمئن شوید jQuery لود شده
   • Console: jQuery
   • باید function ببینید، نه undefined
