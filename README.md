# دایرکتوری آموزشی - Educational Directory Plugin

پلاگین جامع وردپرس برای معرفی و مدیریت آموزشگاه‌ها، مدارس و معلمین با طراحی مدرن و زیبا

## 📋 ویژگی‌ها

### 🏢 مدیریت جامع
- **آموزشگاه‌ها**: ثبت و مدیریت کامل آموزشگاه‌ها با اطلاعات تماس، آدرس، امکانات و...
- **مدارس**: مدیریت مدارس با دسته‌بندی نوع (دولتی، غیرانتفاعی، خصوصی)
- **معلمین**: پروفایل کامل معلمین با تخصص، سابقه، مدرک تحصیلی و هزینه تدریس

### 🎨 طراحی زیبا و مدرن
- رابط کاربری زیبا و کاربرپسند
- طراحی کاملاً ریسپانسیو (موبایل، تبلت، دسکتاپ)
- پشتیبانی کامل از RTL و زبان فارسی
- انیمیشن‌های نرم و حرفه‌ای
- رنگ‌بندی متمایز برای هر بخش

### 🔍 جستجو و فیلتر پیشرفته
- فرم جستجوی قدرتمند
- فیلتر بر اساس شهر، رشته، تخصص و...
- جستجوی زنده
- قابلیت فیلتر با AJAX

### 🏷️ دسته‌بندی هوشمند
- **رشته‌های آموزشی**: ریاضی، فیزیک، زبان و...
- **شهرها**: دسته‌بندی جغرافیایی
- **مقاطع تحصیلی**: ابتدایی، متوسطه، دانشگاهی و...
- **تخصص‌ها**: تخصص‌های مختلف معلمین
- **نوع موسسه**: دولتی، خصوصی، غیرانتفاعی

### 📝 فیلدهای جامع
#### برای آموزشگاه‌ها و مدارس:
- اطلاعات تماس (تلفن، ایمیل، وبسایت، شبکه‌های اجتماعی)
- آدرس کامل و موقعیت جغرافیایی
- امکانات (پارکینگ، کتابخانه، آزمایشگاه، سالن ورزشی و...)
- رتبه‌بندی و امتیاز
- تصویر شاخص و گالری تصاویر

#### برای معلمین:
- سابقه تدریس
- مدرک تحصیلی
- گواهینامه‌ها و مدارک
- هزینه تدریس (تومان/ساعت)
- ارتباط با آموزشگاه‌ها/مدارس
- رتبه‌بندی

### ⚡ Shortcodes قدرتمند
```
[ed_academies] - نمایش آموزشگاه‌ها
[ed_schools] - نمایش مدارس
[ed_teachers] - نمایش معلمین
[ed_search] - فرم جستجو
```

#### پارامترهای Shortcode:
```
[ed_academies limit="12" columns="3" city="tehran" subject="math"]
[ed_schools limit="9" columns="3" orderby="rating"]
[ed_teachers limit="16" columns="4" specialty="physics"]
```

### 🎯 امکانات توسعه‌یافته
- سیستم تمپلیت قابل سفارشی‌سازی
- هوک‌ها و فیلترهای متنوع برای توسعه‌دهندگان
- سازگار با تم‌های مختلف وردپرس
- بهینه‌سازی شده برای SEO
- پشتیبانی از Gutenberg و Classic Editor

## 📦 نصب و راه‌اندازی

### نصب دستی:
1. فایل‌های پلاگین را در پوشه `/wp-content/plugins/educational-directory` قرار دهید
2. به پنل مدیریت وردپرس بروید
3. از منوی "افزونه‌ها" پلاگین را فعال کنید
4. صفحات پیش‌فرض به صورت خودکار ایجاد می‌شوند

### نصب از پنل وردپرس:
1. به افزونه‌ها > افزودن افزونه جدید بروید
2. فایل ZIP پلاگین را آپلود کنید
3. پلاگین را نصب و فعال کنید

## 🚀 استفاده

### ایجاد محتوا:
1. **آموزشگاه جدید**: از منوی "آموزشگاه‌ها" > "افزودن آموزشگاه"
2. **مدرسه جدید**: از منوی "مدارس" > "افزودن مدرسه"
3. **معلم جدید**: از منوی "معلمین" > "افزودن معلم"

### نمایش در صفحات:
```
// نمایش لیست آموزشگاه‌ها
[ed_academies]

// نمایش آموزشگاه‌های تهران در رشته ریاضی
[ed_academies city="tehran" subject="math"]

// نمایش معلمین با فیلتر
[ed_teachers specialty="english" limit="8"]

// فرم جستجو
[ed_search type="all"]
```

## 🎨 سفارشی‌سازی

### تغییر استایل‌ها:
فایل CSS سفارشی خود را به صورت زیر اضافه کنید:

```php
add_action('wp_enqueue_scripts', 'my_custom_ed_styles', 20);
function my_custom_ed_styles() {
    wp_enqueue_style('my-ed-custom', get_stylesheet_directory_uri() . '/custom-ed.css');
}
```

### تغییر متغیرهای رنگ:
```css
:root {
    --ed-primary: #your-color;
    --ed-secondary: #your-color;
}
```

## 🔧 تنظیمات پیشرفته

### تغییر تعداد نمایش در آرشیو:
```php
add_filter('pre_get_posts', 'custom_ed_archive_count');
function custom_ed_archive_count($query) {
    if (!is_admin() && $query->is_main_query() && 
        $query->is_post_type_archive(['academy', 'school', 'teacher'])) {
        $query->set('posts_per_page', 20);
    }
    return $query;
}
```

## 📱 ریسپانسیو

پلاگین به صورت کامل ریسپانسیو است و در تمام اندازه صفحه‌نمایش‌ها به خوبی کار می‌کند:

- **موبایل**: تک ستونی با نمایش بهینه
- **تبلت**: دو یا سه ستونی
- **دسکتاپ**: سه یا چهار ستونی بر اساس تنظیمات

## 🌐 چندزبانه

پلاگین آماده ترجمه است و می‌توانید به راحتی آن را به زبان‌های دیگر ترجمه کنید.

Domain: `educational-directory`
Path: `/languages`
