فایل: templates/single-*.php

❌ قبل:
<div class="edu-main-content" style="display: grid; grid-template-columns: 1fr 350px; gap: 2rem; padding: 2rem;">

✅ بعد:
<div class="edu-main-content">


فایل: assets/style.css
────────────────────────────────────────────────────────

✅ اضافه شد:
.edu-main-content {
    display: grid;
    grid-template-columns: 1fr 350px;
    gap: 2rem;
    padding: 2rem;
}

@media (max-width: 768px) {
    .edu-main-content {
        display: grid !important;
        grid-template-columns: 1fr !important;
        padding: 1rem !important;
        gap: 1.5rem !important;
    }
    
    .edu-main-content > * {
        width: 100% !important;
        max-width: 100% !important;
    }
}

احتمال 1: کش پاک نشده
─────────────────────────────────────────────────────────
راه حل:
• مرورگر را ببندید کاملاً
• دوباره باز کنید
• Ctrl + Shift + Delete
• همه کش را پاک کنید


احتمال 2: تم شما override می‌کند
─────────────────────────────────────────────────────────
راه حل:
• تم را به پیش‌فرض تغییر دهید
• تست کنید
• اگر کار کرد، مشکل از تم شماست


احتمال 3: پلاگین دیگری مزاحم است
─────────────────────────────────────────────────────────
راه حل:
• همه پلاگین‌ها را غیرفعال کنید
• فقط Educational Directory فعال باشد
• تست کنید


احتمال 4: viewport meta tag نیست
─────────────────────────────────────────────────────────
چک کنید:
1. F12 را بزنید
2. بخش Elements یا Inspector
3. تگ <head> را باز کنید
4. دنبال این خط بگردید:
   <meta name="viewport" content="width=device-width, initial-scale=1.0">

اگر نیست:
• تم شما قدیمی است
• باید تم را به‌روز کنید
